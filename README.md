# Mansa Security

Site vitrine de Mansa Security, protection rapprochée et sécurité privée à Manchester, en quatre langues : français, anglais, espagnol et arabe (mise en page de droite à gauche).

Lien direct vers une langue : `#fr`, `#en`, `#es`, `#ar` (le choix du visiteur est ensuite mémorisé).

Pages : `index.html` (site, photos intégrées) et `legal.html` (conditions d'utilisation, confidentialité et cookies, en quatre langues ; la version anglaise prévaut). Publié avec GitHub Pages.

Photos libres de droits (Unsplash, Pexels) à remplacer par les visuels de la marque.

Logo officiel : `assets/mansa-emblem.png` (emblème détouré, fond transparent).
Logos Mansa Security / Executive Protection : `assets/logo/` (fond clair, fond sombre, transparents).
